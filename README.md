# 3단계 - 영화 예매(데이터베이스)

## 구현할 기능 목록

### 1. 데이터베이스 환경 구성
- [x] H2 데이터베이스 의존성을 추가한다.
- [x] JDBC를 사용하여 데이터베이스에 연결할 수 있도록 설정한다.
- [x] 프로그램을 다시 실행하더라도 저장된 데이터를 조회할 수 있도록 파일 기반 데이터베이스로 구성한다.
- [ ] 애플리케이션 실행 시 필요한 테이블을 생성하거나 초기화할 수 있다.

### 2. 상영 정보 영속화
- [ ] 영화의 상영 정보는 데이터베이스에 저장한다.
- [ ] 상영 정보에는 영화, 상영관, 상영일시 정보가 포함된다.
- [ ] 프로그램 실행 시 데이터베이스에 저장된 상영 정보를 조회하여 `Movie`, `Screening`, `Sreenings` 객체로 구성할 수 있다.
- [ ] 기존 `Movie`, `Screening`, `ScreeningDateTime`, `Screen` 도메인 객체의 변경을 최소화한다. 

### 3. 예매 정보 영속화
- [ ] 예매 완료 시 예매 정보를 데이터베이스에 저장한다.
- [ ] 예매 정보에는 예매한 영화, 상영 정보, 선택한 좌석 정보가 포함된다.
- [ ] 하나의 예매는 여러 좌석을 가질 수 있으므로 좌석 정보도 함께 저장할 수 있어야 한다.
- [ ] 프로그램을 다시 실행하더라도 저장된 예매 정보를 조회할 수 있다.
- [ ] 조회한 예매 정보를 기반으로 `ReservedSeats`를 구성할 수 있다.

### 4. 좌석 예약 상태 반영
- [ ] 특정 상영에 대해 이미 예약된 좌석 목록을 조회할 수 있다.
- [ ] 조회한 예약 좌석 정보는 `ReservedSeats`에 반영된다. 
- [ ] 이미 예매된 좌석은 다시 선택할 수 없다.

## 구현 전략
데이터베이스는 H2를 사용하고, 연동 방식은 JDBC를 사용한다.  
상영 정보와 예매 정보를 조회한 뒤 현재 도메인 객체로 복원할 수 있도록 구현하며,  
도메인 객체는 데이터베이스나 SQL을 직접 알지 않도록 유지한다.

테스트는 데이터베이스 저장/조회 자체를 검증하는 테스트와,  
조회한 데이터를 기반으로 기존 도메인 로직이 올바르게 동작하는지를 확인하는 테스트로 나누어 작성한다.
